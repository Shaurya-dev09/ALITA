# ALITA — Personal AI OS

> An Iron Man–inspired personal AI assistant with voice recognition, Hindi-English conversation, system control, and a cinematic HUD-style interface.

## 🎯 About

ALITA (formerly FRIDAY) is a personal AI operating system built from scratch — combining speech recognition, natural language understanding, and system automation into a single voice-controlled assistant, inspired by JARVIS/FRIDAY from Iron Man.

## ✨ Features

- 🎙️ **Voice Recognition & Synthesis** — Real-time speech-to-text and text-to-speech
- 🗣️ **Bilingual Support** — Understands and responds in both Hindi and English
- 🖥️ **System Control** — Automates OS-level tasks and actions
- 🔐 **Voice Authentication** — Secure voice-based identity verification
- 🎨 **Cinematic HUD UI** — Custom dashboard with animated visuals, sidebar navigation, and live system resource meters
- 🧠 **Memory & Context** — Remembers preferences, projects, and past interactions
- 🔧 **Modular Tools** — Extensible tool system (system control, project management, screen tools, image tools)

## 🛠️ Tech Stack

- **Language:** Python 3.11
- **AI Backend:** Google Gemini API
- **Speech:** SpeechRecognition, PyAudio, pyttsx3
- **UI:** Custom-built HUD dashboard
- **Architecture:** Modular design (core / ui / tools / services)
